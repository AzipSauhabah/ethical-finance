Gotcha critique — pdf.py
Toutes les fonctions locales hr, p, f, e, chart, tbl_style, st, _base_styles doivent être définies AVANT le dict styles et AVANT buf = io.BytesIO().

Chaque sous-fonction _pages_*() doit extraire section_s explicitement depuis le dict styles.
